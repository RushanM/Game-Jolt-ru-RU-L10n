Русификатор [Game Jolt](https://gamejolt.com/), реализованный в виде скрипта для [Tampermonkey](https://github.com/Tampermonkey/tampermonkey).

## Установка

1. Установите Tampermonkey или его аналог.
2. Откройте ссылку на скрипт c [GitHub](https://github.com/RushanM/Game-Jolt-ru-RU-L10n/raw/master/GJ-Ru-L10n.user.js) или [GreasyFork](https://greasyfork.org/ru/scripts/496844-game-jolt-russian-translation).
3. Обновите страницу Game Jolt, если она была открыта.
4. Готово!
